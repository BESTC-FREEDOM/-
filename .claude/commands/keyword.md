description: 롱테일 키워드 후보 발굴 후 keywords.csv에 추가
argument-hint: 주제
---
주제: $ARGUMENTS

1. blog/profile.md 의 메인 주제와 독자를 읽는다. 주제가 메인 주제와 어긋나면 먼저 경고한다.
2. 검색 의도(방법, 후기, 비교, 추천, 정보)별로 롱테일 키워드 후보 20개를 만든다. 초반 블로그 기준 월 검색량 300~3,000, 경쟁 낮음을 노린다.
3. 검색량은 추정치임을 명시하고, 네이버 검색광고 키워드도구와 데이터랩에서 확인할 순서를 우선순위(A/B/C)로 제시한다.
4. keywords/keywords.csv 에 status=후보 로 추가한다. 이미 있는 키워드는 중복 추가하지 않는다.
5. 바로 쓸 만한 상위 5개와 이유를 짧게 보고한다.
